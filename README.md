# Bolsa de Valores

Um sistema distribuído de bolsa de valores de alta performance para processamento e casamento de ordens de compra e venda em tempo real. O sistema utiliza um Order Book (Livro de Ofertas) com algoritmo Price-Time Priority, filas de mensagens via RabbitMQ para desacoplamento e assincronismo, e comunicação via WebSockets para atualização instantânea dos clientes.
